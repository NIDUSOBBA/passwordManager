Менеджер паролей - Офлайн Java-приложение
 Описание

Безопасное, полностью офлайн приложение для хранения паролей, разработанное на Java. Хранит email-адреса, аккаунты и пароли. 
 Возможности

    Полностью офлайн - не требует подключения к интернету, все данные хранятся локально

    Защита мастер-ключом - OS-уровневое хранение мастер-ключа (Windows Credential Manager / macOS Keychain / Linux Secret Service)

    Надежное шифрование - все конфиденциальные данные шифруются AES-256

    Удобный интерфейс - простой и интуитивный GUI на Java Swing


 Технологический стек

    Язык: Java (JDK 17)

    UI Фреймворк: Java Swing

    База данных: SQLite (встраиваемая)

    Интеграция с ОС:

        Windows: Windows Cryptography API (CNG)

        macOS: Keychain Services

        Linux: libsecret
Нету валидации паролей, и email поскольку является просто хранлищем для пользователей у которых стало слишком много аккаунтов которые надо запоминать.
